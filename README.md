## Adding a project

1. Put the site in a new top-level folder, e.g. `NewProject/`, with `index.html` at its top and relative asset paths.
2. Add a 16:10 `cover.jpg` (about 800×500) to that folder.
3. In the root `index.html`, copy an `<a class="project">` block and change the folder, title, year and description.

The site appears at `https://mmbalbuenajr-hue.github.io/Portfolio/NewProject/`. Folder names are case-sensitive in the URL.

`.nojekyll` makes Pages serve every file as it is.
